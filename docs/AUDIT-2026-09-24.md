# AUDIT-2026-09-24 — consolidated audit of release 3.0.0

**Date:** 2026-09-24. **Base:** `main` at `b8de3916` ("chore: релиз 3.0.0").
**Verdict:** release-blocker H1 found and fixed; everything else is fixed,
documented, or an accepted risk — see the findings table.

## Scope and method

Five audit angles, each walked over the 3.0.0 tree (glide typing, personal
bigrams, incognito, height presets, the restructured settings host):

1. **Security & privacy** — manifest/permissions discipline, data flows of the
   personal stores, logging surface, exported components, the privacy policy's
   fidelity to the code.
2. **Performance** — baseline profile coverage of the new glide code, memory
   shape of two live engines, allocation hot spots, legacy statics.
3. **Correctness** — the revert path, learning counters, geometry staleness,
   quarantine flows, error-prone deltas of phase 7.
4. **Data & licenses** — NOTICE files vs the shipped assets, pin coverage of
   the emoji tables, attribution sufficiency (Leipzig, Tatoeba, OpenSubtitles,
   FlorisBoard).
5. **UI/UX** — strings (en/ru/tt), the review-queue discipline, settings
   screens, accessibility, link hygiene.

## Verdicts per area

- **Security: PASS.** No INTERNET, backup fully excluded, no typed-content
  logging. One release blocker found outside the code proper: the in-app
  privacy/license URLs pointed at the old repository owner (H1) — fixed in this
  wave. The remaining items are minor documentation gaps (fixed) or documented
  INFO-level observations.
- **Performance: PASS with two accepted notes.** The glide classes were missing
  from the baseline profile (fixed by the F1 wave's regeneration); the
  worst-case ~5.8 MB of two warm glide word indexes is recorded as an accepted
  decision; PointerTracker statics stay as accepted legacy.
- **Correctness: PASS after the F1 wave.** Two MAJOR findings (the revert path
  missing `isConnected`, dead word-usage updates) and five MINOR ones are fixed
  in the F1 wave; the four new error-prone warnings are triaged.
- **Data & licenses: PASS after this wave.** NOTICE staleness fixed, emoji
  search/skin pin gaps closed, FlorisBoard attribution verified sufficient.
- **UI/UX: PASS after this wave + F1.** H1 (repo links) fixed here; M1/L5/L8
  fixed in F1; the rest fixed here, documented, or accepted.

## The fix wave

Two parallel waves land the "fixed-in-3.0.1" rows:

- **F1 (app code):** the correctness MAJORs and MINORs (revert `isConnected`,
  dead word-usage updates, neighbor geometry, pair boundary, onTap guard,
  quarantine flags, double pending read), the three LongFloatConversion casts,
  the baseline-profile regeneration, M1 (restriction titles), L5 (empty
  add-language dialog), L8 (chevron autoMirrored).
- **DOCS/DATA/STRINGS (this wave):** both NOTICE files, PRIVACY.md → 1.6,
  the error-prone triage entry, the ROADMAP-P7 memory footnote, the emoji
  search/skin pins, the strings fixes (H1 repo links, L7 https, L6 orthography,
  ru plural), the review-queue backfill, the KDoc, this report.

Gates of this wave (2026-09-24): python suites **507 tests in 16 files, 0
failing** (505 + 2 new pin tests; the pre-existing emoji_pack regeneration skip
stands). The full gate set (JVM, lint, release) is run by the F1 wave on the
merged tree.

## Residual risks (accepted / parked)

- **L3 contrast 4.0:1** in the light theme — the accepted iOS-palette decision;
  revisited only with a design pass.
- **PointerTracker statics** — accepted AOSP legacy; a rewrite is not worth the
  regression risk.
- **TalkBack audible check** — the mechanics are pinned by tests and
  screenshots; the final ears-on check stays with the operator.
- **SettingsActivity exported** — required by the IME settings contract;
  accepted.
- **~5.8 MB worst-case glide memory** — accepted; freed on engine destroy /
  geometry swap (`docs/ROADMAP-P7.md` footnote, 2026-09-24).
- **Metadata logging** (LatinIME ×2, restriction values) — documented; no
  typed text is ever logged.
- **sentstart assets outside the release gates** — documented; adding them to
  `release_check.sh` is optional.
- **FLAG_SECURE on dialogs (I2)** — documented defence-in-depth idea, not
  scheduled.
- **Silent disabled rows (L4)** — documented behavior.
- **No scrollbars (I3)** — accepted style.
- **ClassInitializationDeadlock** on `EMPTY_LISTENER` — documented as
  unreachable in practice (UI-thread-only initialization).
