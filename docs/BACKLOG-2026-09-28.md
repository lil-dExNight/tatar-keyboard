## C. Новая фича: эмодзи, выученные по сочетаниям пользователя

**Запрос оператора (2026-09-28):** сейчас после набора «хәйерле иртә» полоса
предлагает один статический смайлик (🌅). Если пользователь всегда ставит
другой (☀️), клавиатура должна это запоминать и предлагать ЕГО в следующий раз.

**Текущая механика:** `EmojiSuggestIndex` — статическая таблица (lang, word) →
emoji (`emoji_suggest_v1.txt`, ~3 976 записей), хвостовая ячейка
NEXT_WORD-полосы; свой тоггл (`pref_emoji_suggestions`, по умолчанию ON, под
мастером подсказок).

**Дизайн-набросок (под существующую архитектуру):**

- **Хранилище:** личная карта `normalizedWord → emoji`, per язык, с счётчиком
  использований. Формат — как у личных пар (fail-closed валидатор, атомарная
  запись, `noBackupFilesDir`, солёные pending-хэши до порога), НО эмодзи не
  проходят алфавитный фильтр слов — отдельный маленький файл (например
  `.tpersem`) или расширение формата пар. Кап ~500 записей, LRU по serial.
- **Обучение:** событие «после закоммиченного слова пользователь вставил
  эмодзи» (из панели, поиска или чужой вставки? — только панель/поиск/тап по
  полосе, т.е. наши собственные вставки; вставка из буфера не учится — правило
  как у CleanRunMachine). Порог как у пар: с 2 наблюдений выученный эмодзи
  лидирует в хвостовой ячейке ЭТОГО слова, отодвигая статический. Мульти-эмодзи
  кластер (☀️😊) записывается целиком (логика кластеров уже есть в
  `EmojiTextUtils`).
- **Ранжирование:** слой перекрытия поверх статической таблицы: сначала
  выученное, потом статическое; два разных выученных — по счётчику. Никогда не
  автовставлять — только предложение.
- **Гейты:** мастер подсказок → тоггл эмодзи-подсказок → личный словарь ON →
  инкогнито OFF (пауза обучения, чтение продолжается) → разблокировка. Всё как
  у личных слов/пар.
- **UI:** экран «Шәхси сүзлек» получает третий список (или пары-экран
  расширяется): выученные эмодзи с счётчиками, forget/очистка. FLAG_SECURE уже
  на месте.
- **Тесты:** формат fail-closed, порог обучения, перекрытие статики, кап/LRU,
  инкогнито, забвение; e2e контроллера; device-нога: добавить, выбрать ☀️ дважды
  после «хәйерле иртә», увидеть ☀️ первым.
- **Чего НЕ делать:** не учить по словарным словам автозамену эмодзи; не
  вытеснять статический ряд полностью (выученный — только лидер ячейки); не
  писать ничего при выключенных тогглах; не пускать чужой буфер обмена.

**2026-09-28:** SHIPPED — хранилище .tpersem (порог 2, кап 500 LRU,
fail-closed, солёные pending), обучение из трёх своих вставок (панель/поиск/
тап по полосе; буфер не учится), перекрытие статики только лидером ячейки,
гейты как у пар, третий список в «Шәхси сүзлек» + quarantine-попап; отчёт
`docs/EMOJI-LEARN.md`; device-нога: зонд learned-emoji-tt — ☀️ вытеснил
статический 🌅.
