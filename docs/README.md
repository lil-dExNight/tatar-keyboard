# Документация tatar-keyboard — индекс

Живые документы лежат наверху `docs/`, отчёты завершённых миссий — в
`docs/archive/` по тематическим категориям. Архив не редактируется
(историческая запись); актуальное состояние проекта — в корневом `HANDOFF.md`.

- `CLEANUP.md` — журнал очистки документации; свидетельства в `cleanup/`.
- `RESTRUCTURE.md` — журнал кампании аудита/реструктуризации/оптимизации (2026-08-30).
- `RESTRUCTURE-PLAN.md` — утверждённый план той же кампании.
- `APK-AUDIT-1.9.15.md` — аудит артефакта текущего релиза (1.9.15);
  `APK-AUDIT-1.9.14.md`, `APK-AUDIT-1.9.13.md`, `APK-AUDIT-1.9.12.md`, `APK-AUDIT-1.9.11.md`, `APK-AUDIT-1.9.10.md`, `APK-AUDIT-1.9.9.md`,
  `APK-AUDIT-1.9.8.md`,
  `APK-AUDIT-1.9.7.md`, `APK-AUDIT-1.9.6.md`, `APK-AUDIT-1.9.5.md` — предыдущих;
  аудиты более ранних версий — в `archive/apk-audits/`.
- `DEV-PLAN.md` — план улучшений разработки (tooling, тесты, CI; без продуктовых

- `AUDIT-2026-08-31.md` — полный аудит (безопасность, UX, оптимизация) с
  находками и рекомендуемым порядком закрытия. **Все находки закрыты
  2026-08-31** (датированные пометки внутри), итог — релиз-кандидат 1.9.6.
- `SIZE-OPTIMIZATION-RESEARCH.md` — ресерч ужатия APK без потерь (2026-09-01):
  измеренный потенциал −29 % сменой бинарной схемы словарей/биграмм; с датированной
  финальной пометкой о фактическом результате (−15,3 %).
- `EMOJI-SUGGEST-RESEARCH.md` — ресерч эмодзи-подсказок в полосе подсказок
  (2026-09-01): вердикт — вариант A (append на завершённом слове), курируемые
  данные, отдельный тоггл.
- `EMOJI-SUGGEST-PLAN.md` — план реализации эмодзи-подсказок (3 миссии).
  **Все три миссии выполнены 2026-09-01** — релиз 1.9.10.
- `FINAL-AUDIT-2026-09-02.md` — финальный предрелизный аудит 1.9.11
  (безопасность, баги, производительность, полнота): единый реестр долгов.
  **Всё закрыто 2026-09-02**, кроме операторских (A2 публикация, C8 jks) и
  железных (D1/D2) пунктов — релиз 1.9.12.
- `DEVICE-UAT-1.9.12.md` — первая полная проверка на живом устройстве
  (2026-09-04, POCO C71 / Android 15 Go): холодный старт (медиана 300,6 мс),
  PSS по фазам, матрица из 36 сценариев, все гейты репозитория. Закрывает D1 и
  большую часть D2. Два дефекта, оба закрыты 2026-09-04: Д-1 (панель эмодзи под
  навбаром) и Д-2 (нет Enter на планшетах). Свидетельства — `device-uat/evidence/`.
- `ERRORPRONE-TRIAGE.md` — разбор всех 64 находок error-prone (2026-09-05):
  закрыто 5, среди них настоящий латентный NPE в загрузке управляемых политик
  (ограничение цвета не-строкового типа роняло весь разбор). Остальные 59
  разобраны по классам с обоснованием, почему остаются.
- `RESEARCH-FIXES.md` — миссия починки находок ресерча (2026-09-04, релиз 1.9.14):
  текст клавиатурных поверхностей переведён с sp на dp (Р-3), панель эмодзи
  уважает «Нижний отступ» (Р-1) и сжимает свои полосы при малой высоте (Р-2);
  витринные заметки английской локали переписаны по-английски.
- `DEVICE-RESEARCH-GEOMETRY.md` — ресерч оставшихся проблем на живом устройстве
  (2026-09-04, поверх релиза 1.9.13): перебор пользовательских настроек по оси
  геометрии. Три находки — панель эмодзи игнорирует «Нижний отступ» (Р-1), при
  малой высоте клавиатуры панели не остаётся места (Р-2), полоса подсказок
  вырождается при крупном системном шрифте (Р-3). Ни одна не блокирует релиз.
- `EMOJI-PANEL-NAVBAR.md` — миссия починки Д-1 (2026-09-04): панель эмодзи
  перестала уходить под панель навигации на Android 15; перекрытие меряется
  через `getWindowVisibleDisplayFrame`, инвариант запинен `EmojiPanelStateTest`.
  Версия не бампалась.
- `TABLET-ENTER.md` — миссия починки Д-2 (2026-09-04): собственный нижний ряд
  кириллических раскладок `row_cyrillic4`, инвариант «Enter/delete/shift на
  каждом классе экранов» запинен `EnterKeyPresenceTest`. Версия не бампалась.
- `emoji-suggest/DATA.md` — миссия 1 плана эмодзи-подсказок (2026-09-01):
  курируемый ассет «слово → эмодзи» `emoji_suggest_v1.txt` (ru+tt, 681 понятие,
  3 825 записей), метод, denylist полисемии, протокол вычитки —
  `emoji-suggest/evidence-data-review.txt`.
- `emoji-suggest/ENGINE.md` — миссия 2 плана эмодзи-подсказок (2026-09-01):
  движок — эмодзи в хвостовой ячейке NEXT_WORD-полосе, append через
  `commitPredictedWord`, свой тоггл (opt-in), a11y-лейблы, эмуляторные
  свидетельства в `emoji-suggest/evidence/`.
- `emoji-suggest/FIXES.md` — миссия 4 плана эмодзи-подсказок (2026-09-02):
  три полевых дефекта — tt-покрытие поиска эмодзи (200 → 1318/1389,
  «этэч»→🐓), дефолт тоггла эмодзи-подсказок ON + конфузиблы
  («йорэк»→❤️), сброс поиска эмодзи при скрытии клавиатуры;
  до/после — `emoji-suggest/evidence/m4*.png`.
- `NEXTWORD-RACE.md` — закрытие хвоста «первый NEXT_WORD-запрос пуст»
  (2026-09-01, поверх 1.9.10): два дефекта под одним
  симптомом — страж границы кэша `extractNextWordContext` (доминирующий) и
  гонка attach E5c; свидетельства в `nextword-race/`. **Вошло в 1.9.11.**
- `SIZE-CAMPAIGN.md` — итоговый отчёт кампании ужатия (три миссии SIZE-1/2/3,
  таблица до/после, доказательства lossless, latency) — релиз 1.9.9;
  свидетельства живого обновления в `size-campaign/evidence/`.
- `SIZE-SCHEMA2.md` — миссия SIZE-1 (2026-09-01): словари переведены на TATDICT
  schema 2 (front-coding K=8 + u8-длины + varint-частоты), lossless, −198 КБ
  в словарных ассетах; дизайн, доказательство эквивалентности, latency.
- `SIZE-SCHEMA3.md` — миссия SIZE-2 (2026-09-01): таблицы биграмм переведены на
  TATBIGR schema 3 (кросс-референс в словарь: дельта-varint голов, varint-индексы
  преемников, u8-счётчики, связка со словарём по raw SHA-256), lossless, −182 КБ
  в таблицах; дизайн, эквивалентность (20 202 головы), latency.
- `RUSSIAN-BIGRAMS-REPACK.md` — перепаковка русской таблицы биграмм от текущего
  словаря (дрейф 4 195/4 195 закрыт) — 1.9.7; свидетельства в
  `russian-bigrams-repack/`.
- `CORPUS-CONVERSATIONAL-RU.md` — разговорный корпус, часть A: русская таблица
  биграмм дообучена на дедуплицированных Tatoeba + OpenSubtitles (прореживание
  1/60); 57 из 59 молчавших слов топа заговорили — вошло в 1.9.8;
  свидетельства в `corpus-conversational/`.
- `CORPUS-CONVERSATIONAL-TT.md` — разговорный корпус, часть B: татарская таблица
  дообучена на том же источнике (без прореживания — масса 3,7 %), список
  extra-heads расширен правилом 13 → 75; все шесть повелений за рангом 15 000
  заговорили — вошло в 1.9.8; свидетельства в `corpus-conversational/evidence/`
  (включая снимки полосы предсказаний релиза `release-198-*.png`).
- `restructure/evidence/` — снимки и дампы эмуляторных прогонов кампании
  (фазы 3б, 4а, 4б, 5).
