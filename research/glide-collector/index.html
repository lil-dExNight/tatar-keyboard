Gesture trace collector

This page collects swipe traces of prompted words on an on-screen keyboard, for calibrating an offline Tatar/Russian gesture decoder.

Each kept record contains exactly: the prompt word, the trace resampled to 50 points in key-radius units, per-point timing, the layout id, the screen density bucket, the board size in pixels, and a random participant id shown on the next screen. The page has no text fields: it never sees anything you type anywhere else.

Records stay in this browser's local storage and leave it only when you download them yourself and send the file to the researchers. You can delete single records or all of them at any time. The page makes no network requests — once it has loaded, you can switch to airplane mode and everything keeps working.
