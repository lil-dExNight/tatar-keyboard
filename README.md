# Tatar Keyboard

![CI](https://github.com/lil-dExNight/tatar-keyboard/actions/workflows/ci.yml/badge.svg)

A native Android keyboard with a Tatar Cyrillic layout: the standard ЙЦУКЕН plus a dedicated, always-visible fifth row for **ә ө ү җ ң һ**. Word suggestions, next-word prediction, glide typing and an emoji panel all work on the device. The app has no INTERNET permission; CI checks this on every commit. Lightweight, fast on budget devices, open source under Apache-2.0.

---

## О проекте

**Tatar Keyboard** — татарская клавиатура для Android. Стандартная раскладка ЙЦУКЕН плюс отдельный видимый пятый ряд татарских букв **ә ө ү җ ң һ**: ничего не нужно зажимать и искать, все 39 букв татарского алфавита доступны одним нажатием. В Gboard и SwiftKey татарские буквы спрятаны под долгое нажатие.

Цель — печатать по-татарски так же быстро, как по-русски, на недорогом телефоне и без интернета.

### Возможности

- **Татарская раскладка**: ЙЦУКЕН + видимый пятый ряд ә ө ү җ ң һ
- **Три языка**: татарский (tt_RU), русский, английский (en_US) — переключение клавишей-глобусом
- **Подсказки слов (по желанию)** для татарского и русского: полоса из трёх ячеек над клавиатурой — дополнение набираемого слова и предсказание следующего; учитываются частые опечатки. По умолчанию выключены и не показываются в полях пароля и других приватных полях. Тап подставляет слово вместе с пробелом; перед знаком препинания и там, где пробел уже есть, лишний не добавляется
- **Исправление слов (по желанию)**: при пробеле или знаке препинания слово с опечаткой исправляется; backspace сразу после этого возвращает набранное. По умолчанию выключено, работает только вместе с подсказками
- **Набор свайпом** для татарского и русского: проведите пальцем по буквам слова, не отрывая его; слово вставляется при отпускании, а при включённых подсказках другие варианты появляются в полосе. Включён по умолчанию, отключается в настройках
- **Панель эмодзи**: категории, поиск, вкладка недавних; высота панели настраивается (как у клавиатуры, больше, максимум). Открывается отдельной клавишей рядом с пробелом или, когда показана клавиша-глобус, долгим нажатием на запятую
- **Подсказки эмодзи** (вместе с подсказками слов): после законченного татарского или русского слова в полосе предлагается подходящий эмодзи; тап добавляет эмодзи, слово остаётся
- **Личный словарь (по желанию)**: по умолчанию выключен. Запоминает набранные вами слова, пары слов («какое слово за каким») и эмодзи, которые вы ставите после определённых слов, и предлагает их в подсказках. Слово можно добавить и вручную. Всё сохранённое видно и стирается на экране «Сохранённые слова»; режим инкогнито приостанавливает обучение. Ничего не покидает устройство
- **Long-press дубли**: на русской раскладке татарские буквы доступны долгим нажатием (а→ә, о→ө, у→ү, ж→җ, н→ң, х→һ), плюс е→ё и ь→ъ
- **Знакомая эргономика**: минималистичный вид, светлая и тёмная темы, настраиваемая высота клавиатуры, отдельный ряд цифр по желанию
- **Быстрая печать**: двойной пробел → точка, свайп по пробелу двигает курсор, multi-touch без потери букв
- **Мгновенный отклик**: баллон-превью при нажатии, панель альтернатив, звук и вибрация (настраиваются)
- **Доступность**: поддержка TalkBack с описаниями татарских букв («татарская э» для ә)
- **Онбординг**: два шага от установки до первой татарской буквы
- **Работает до первой разблокировки** (directBoot): клавиатура доступна для ввода PIN сразу после перезагрузки

### Установка

1. Скачайте APK из [GitHub Releases](https://github.com/lil-dExNight/tatar-keyboard/releases) репозитория [lil-dExNight/tatar-keyboard](https://github.com/lil-dExNight/tatar-keyboard).
2. Разрешите установку из неизвестных источников (система спросит сама).
3. Откройте приложение — онбординг из двух шагов проведёт через включение и выбор клавиатуры.

**Требования:** Android 7.0+ (minSdk 24).

### Приватность

**Ничего не уходит с устройства.** В манифесте приложения нет разрешения INTERNET, поэтому само приложение ничего никуда не отправляет: всё, что вы печатаете, обрабатывается только на устройстве. CI проверяет манифест и собранный APK на каждом коммите. Та же проверка подтверждает, что данные приложения исключены из резервного копирования и переноса на новое устройство (`allowBackup=false`); поэтому настройки клавиатуры на новом устройстве нужно задать заново. Нет аналитики, рекламных SDK и Firebase.

Локально клавиатура сохраняет только то, что нужно для работы подсказок: до 24 недавно использованных эмодзи и, если вы включите личный словарь (по умолчанию выключен), набранные вами слова, пары слов и выученные эмодзи. Всё это лежит во внутренней папке, которая расшифровывается только после разблокировки устройства, не попадает в облачную резервную копию, видно и стирается в настройках. Подробности — в [PRIVACY.md](PRIVACY.md) (на английском).

### Сборка из исходников

Требуется JDK 17 и Android SDK. Файл `gradle/wrapper/gradle-wrapper.jar` намеренно не хранится в репозитории — восстановите его командой `gradle wrapper` (Gradle 9.6) или скачайте из официального тега [gradle/gradle v9.6.0](https://github.com/gradle/gradle/blob/v9.6.0/gradle/wrapper/gradle-wrapper.jar) (CI делает так же, с проверкой sha256). Затем:

```
./gradlew assembleDebug
```
