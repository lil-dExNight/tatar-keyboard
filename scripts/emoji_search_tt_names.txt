# search announcements). CLDR 44 ships no Tatar emoji annotations, so the names are
# derived from the hand-written keyword file emoji_search_tt_extra.txt (its first
# synonym) where it covers the sequence, and hand-translated where it does not
# (arrows, zodiac signs, keycaps, CJK-symbol buttons). Names are lowercase NFC and
# spelled from the Tatar alphabet plus space and hyphen — the same rule
# scripts/emoji_search_pack.py enforces on --tt-extra. A name must identify one
# emoji: an emoji without a name of its own is left out and is read by its Russian
# name. The packer's --tt-names option validates this file and writes the fourth
# field of emoji_search_v1.txt.
